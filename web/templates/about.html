a browser for curated single-cell RNA-seq data

anthive makes a collection of curated single-cell RNA-seq datasets explorable in the browser — no download, no setup. Each dataset can be filtered, plotted (embeddings, distributions, differential expression, module scores) and exported, straight from the catalogue. The same data is reachable programmatically through a REST API, an MCP server, and in-browser Python notebooks.
