Facet DE, gene sets per cell type{{ doc_toggle('fxs-about', 'About the gene set results') }}

{% call doc_block('About the gene set results', id='fxs-about') %}

Each gene set is scored per donor in each cell type and tested like a gene: the facet is compared between donors, adjusting for the same covariates. Three variants exist: the pseudobulk score (the gene set's mean expression in the donor's summed counts, where counts exist), and the mean over the donor's cells of the per-cell scanpy score or UCell score. Which variant is the main one is not decided yet, so you can switch.

A gene set counts as significant when its q is below 0.05, using the model q when the test has at least 30 residual degrees of freedom and the permutation q otherwise (the rule replication across cohorts uses). Up and down follow the sign of the standardised effect (the change in standard deviations of the donor score). The number of significant gene sets grows with the number of donors, so compare cells within this dataset, not colours across datasets (gene set scores).
