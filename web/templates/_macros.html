{# Sitewide Jinja macros — import with: {% from "_macros.html" import col_label, breadcrumb %} in any template that renders obs column names or a breadcrumb trail. #} {# breadcrumb(trail, ids=None) Renders a unified breadcrumb row used on every page. Args: trail: List of (label, href) tuples. Three possible href values: - a non-empty string → rendered as a link - "" (empty string) → plain muted text, no link, not bold (intermediate label without a page) - None → bold .bc-current span (the active page) A "home" link (href="/") is always prepended automatically. ids: Optional list of (key, value) tuples for copy-chip IDs shown right-aligned on the same row. Example: [("collection", "SP4"), ("dataset", "SP4/MTH")]. Each chip is clickable and copies its value to the clipboard (JS in base.html handles the click). The home icon is the word "home" styled as a muted link — keeps it subtle and screen-reader-friendly. #} {% macro breadcrumb(trail, ids=None) -%}
home {%- for label, href in trail -%} / {%- if href is none -%} {{ label }} {%- elif href -%} {{ label }} {%- else -%} {{ label }} {%- endif -%} {%- endfor -%} {%- if ids -%} {%- for key, value in ids -%} {{ key }}{{ value }} {%- endfor -%} {%- endif -%}
{%- endmacro %} {# col_label(name): display transform for obs column names. canonical (ant_*) → bold stripped label + subdued "canonical" pill + hover ⓘ non-canonical → plain text, unchanged The ant_* value is always the real form used in URLs/API calls — this macro only affects what the user sees on screen. #} {% macro col_label(name) -%} {%- set _ci = obs_col_info(name) -%} {%- if _ci.is_canonical -%} {{ _ci.display_name }}canonical {%- else -%} {{ name }} {%- endif -%} {%- endmacro %}
