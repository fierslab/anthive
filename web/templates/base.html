Your data stays in your browser. Plot preferences are stored locally — no analytics or tracking. details ▾
What's stored, where, and why:
  • anthive.plot.settings — your figure size, DPI, font, palette. Written when you change a setting on a plot page.
  • anthive.storage.notice.ack — that you closed this notice (without it the notice would re-appear on every reload).
  • If you visit /jupyter/, JupyterLite stores your notebook contents, kernel state, and micropip-installed Python packages locally (typically in IndexedDB and localStorage). This is what lets the browser act as your "notebook server" — there is no server-side notebook execution. None of this leaves your browser.
All entries are kept in your browser's localStorage / IndexedDB — they are never sent to the catalogue server, and no third party can read them. They persist until you clear browser data or click "clear my data" below.

Cookies: the catalogue UI (this site, ant-browse) does not set any HTTP cookies. The catalogue's REST API (ant-serve) returns Cache-Control headers for cached plot images but no identifying cookies. The reverse proxy (Caddy) and any TLS-terminator in front of this site may set short-lived session cookies for their own routing — those expire when you close the tab.

Logs: the server records HTTP requests (URL, status, timestamp) for operational debugging. These do not contain plot preferences and are not shared with third parties. Anonymous access logging falls under GDPR Art. 6(1)(f) (legitimate interest in security and uptime monitoring).

Legal basis: the local-storage usage above is functional / strictly necessary under ePrivacy Art. 5(3) and therefore does not require prior consent. This notice is informational. You can clear all stored data at any time using the button below — the catalogue keeps working without it (you'll just see plot defaults instead of your saved preferences).
