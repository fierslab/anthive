{% call doc_block('About artefacts', id='art-help') %}

An artefact is an analysis file deposited with a dataset or a collection: a differential expression table, a figure, a table, a notebook, a report or a model. A published version never changes; a correction is a new version, and old versions stay until their owner or an admin purges them. Downloads come straight from the object store through a link that is valid for a few minutes. Files are always downloaded, never opened in the page. More in the help.
