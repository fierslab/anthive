For each cell type this tab shows where the {{ what }} sits relative to all other {{ peers }} in the same dataset, so you see where it is expressed most strongly compared with everything else. The value is a percent: 76% means the {{ what }} has a higher mean than 76% of the {{ peers }} of that dataset. A longer bar and a higher percent mean stronger expression relative to the rest. The ranking is done inside one dataset only, so it does not depend on how a study normalised its counts, and ranks are never pooled across datasets other than as a median.

Cell type rows

The value of a cell type row is the median percent over its datasets; the n in brackets after the cell type is the number of datasets pooled, and the Cells column is the total number of cells in them. Cell types are sorted by that median, strongest first. Open a row to see its datasets, one line each: the name (one link to its page; hover or focus it for the title, authors, category, nuclei or cells, organism, tissue and size), the cells, the bars, and the Plots column with the histogram, the ECDF and the embedding plot (UMAP, else t-SNE, else PCA) of the {{ what }} in that dataset, the same icons as on the dataset Genes tab. The dotted line marks the median of the cell type.

{% if kind == 'gene' %}

What the percent is

The percent of genes detected in the dataset whose average expression over all cells (cells without a count counted as zero) is lower than that of {{ subject }}. It compares genes, not cells. Values below about 50% mostly mean the gene is barely expressed. Datasets in a cell type row consist of one known cell type, so this is the rank within that cell type. Genes with no count in any cell of the dataset are not part of the comparison. The baseline depends on how many genes a dataset kept, so ranks are compared within one dataset, never as a shared scale.

Colours

Each metric has its own muted colour, the same in every row and on the dataset Genes tab: teal for cells expressing, slate blue for the rank, sand for the standard deviation.

Cells expressing

The second bar is the percent of the cells of the dataset with at least one count of {{ subject }} (the median over datasets in a cell type row). Bulk samples have no cells, so it reads n/a for them.

Std. dev.

The standard deviation of the log-normalised expression of {{ subject }} over all cells of the dataset, cells without a count included as zero (over samples for bulk datasets). It depends on the normalisation and depth of each dataset, so it is shown per dataset only and left blank on cell type rows, where a median over datasets would mix different scales.

{% else %}

What the percent is

The share of the other gene sets scored on the same cells of the same dataset that have a lower mean scanpy score than {{ subject }}, ties counting half. The scanpy score subtracts the mean of a matched control set of genes, so the means of different sets in one dataset are comparable. UCell is not used because it depends on the number of genes in a set. Only gene sets that apply to the cell type of the dataset are compared: a set built for one cell type is scored on those cells only, and sets that apply to every cell count everywhere. For microglia datasets this means the microglia sets plus the general sets, not the astrocyte sets. It needs at least 10 other sets scored on at least 20 cells, otherwise it reads n/a. The first visit of a dataset can take a moment while its scores are read.

{% endif %}

Same definition for genes and gene sets

Both pages rank the mean of the {{ what }} against the means of its peers in the same dataset and show the same bar. The unit differs (genes by mean expression, gene sets by mean score), so the percent of a gene and of a gene set are not interchangeable numbers.

Dataset categories

A dataset whose cells are all of one known cell type (for example sorted or cultured microglia) sits in that cell type's row, whatever its system, with a tag for its category: post-mortem, xenograft (human cells in a mouse brain), biopsy, in vitro or bulk. Only tissue datasets (post-mortem, xenograft, biopsy) enter the median of the row; in vitro and bulk datasets are listed in the opened row after the pooled ones, under the label "In vitro and bulk (not in the summary)": cultured cells and bulk samples are shown for comparison but not used for the cell type summary, because they are not tissue and bulk has no single-cell detection. Detection is not comparable between nuclei and whole cells, so each dataset also carries a nuclei or cells tag (xenograft datasets are sorted live cells).
