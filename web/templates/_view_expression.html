For each cell type this tab shows where the {{ what }} sits relative to all other {{ peers }} in the same dataset, so you see where it is expressed most strongly compared with everything else. The result is a percentile, written "top x%": a bar that is almost full means the {{ what }} is among the most highly expressed {{ peers }} of that dataset. The ranking is done inside one dataset only, so it does not depend on how a study normalised its counts. Ranks of different datasets are never pooled into one number across cell types.

Cell type rows

The value of a cell type row is the median percentile over its datasets, and the number of datasets is given next to it. Cell types are sorted by that median, strongest first, so the top row is where the {{ what }} stands out most. Open a row to see its datasets: one bar per dataset, the dotted line marks the median of the cell type, and the links open the dataset page and a plot of the {{ what }} in that dataset.

{% if kind == 'gene' %}

What the rank is

The percentile of the mean (log-normalised) expression of {{ subject }} among all genes found in the dataset: the share of those genes with a lower mean, taken over all cells of the dataset. Datasets in a cell type row consist of one known cell type, so this is the rank within that cell type. Genes with no count in any cell of the dataset are not part of the comparison. The percent of cells that express the gene is shown in small text next to the number of cells.

{% else %}

What the rank is

The percentile of the mean scanpy score of {{ subject }} among the other gene sets scored on the same cells of the same dataset: the share of those sets with a lower mean score, ties counting half. The scanpy score subtracts the mean of a matched control set of genes, so the means of different sets in one dataset are comparable. UCell is not used because it depends on the number of genes in a set. Only gene sets that apply to the cell type of the dataset are compared: a set built for one cell type is scored on those cells only, and sets that apply to every cell count everywhere. For microglia datasets this means the microglia sets plus the general sets, not the astrocyte sets. It needs at least 10 other sets scored on at least 20 cells, otherwise it reads n/a. The first visit of a dataset can take a moment while its scores are read.

{% endif %}

Same definition for genes and gene sets

Both pages rank the mean of the {{ what }} against the means of its peers in the same dataset, and show the same bar, so the two views read the same way. The unit differs: genes are ranked by mean expression, gene sets by mean score, and the ranks of a gene and of a gene set are not interchangeable numbers.

Dataset categories

Rows are cell types across all datasets, not split by system. A dataset whose cells are all of one known cell type (for example sorted or cultured microglia) sits in that cell type's row, whatever its system, with a tag for its category: post-mortem, xenograft (human cells in a mouse brain), biopsy, in vitro or bulk. Only tissue datasets (post-mortem, xenograft, biopsy) enter the median of the row. In vitro and bulk datasets are listed in the opened row and marked "not pooled".

Datasets without per-cell cell types

The datasets under this header are listed one by one at the bottom. Their cells are a mixture or have no per-cell cell type (whole-tissue objects, spatial and unclassified datasets), so the rank describes the whole dataset and should be compared with the cell type rows with care.

Nuclei and cells

Detection is not comparable between nuclei and whole cells, so each dataset carries a tag for which it is. Xenograft datasets are sorted live cells.
