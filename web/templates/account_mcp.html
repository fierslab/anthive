MCP links

MCP lets an AI assistant such as Claude, Codex, Gemini CLI, Cursor or VS Code search and plot the anthive datasets on your behalf. Each link is private and identifies you. Make one per client (a laptop, Claude Desktop, a notebook server) so you can replace or revoke one without touching the others.

Treat every link like a password. Anyone who has it can query the data as you. If you think one leaked, rotate it: the old link stops working immediately.
