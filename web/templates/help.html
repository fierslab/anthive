Anthive — a quick tour

Anthive is a single-cell RNA-seq browser focused on microglia and astrocyte datasets relevant to Alzheimer's disease. {% if n_datasets is not none %}It currently holds {{ n_datasets }} datasets{% if n_collections is not none %} across {{ n_collections }} collections{% endif %}{% if n_genesets is not none %}, plus {{ n_genesets }} registered gene sets{% endif %}.{% endif %} Everything is server-rendered around a REST API — no data leaves this server until you export it.

Getting around

  • Landing page — the full catalogue, grouped by collection. Column headers filter and sort; state persists via a #mv= hash so a filtered view is shareable.
  • Collection page (/browse/<group>) — one collection's datasets. Constant metadata is hoisted to the header as pills; only fields that vary get their own column.
  • /browse/<group>/<file> — one dataset. IDs at the top are copy-clickable.
  • Genesets (/genesets) — the gene-set / starCAT / find-by-gene browsers.
  • Gene atlas (/genes/<gene>) — a single gene's stats across every dataset.

The dataset page — tabs

Each dataset renders a tabbed page. Tabs only show when their data is present:

Overview markdown description, caveats, provenance.
Data obs columns, embeddings, matrix shape.
Genes per-dataset gene stats + your favourites.
Genesets module scores computed for this dataset.
Numerical distributions of continuous obs fields.
Categorical distributions of categorical obs fields.
Differential expression studies × terms × contrasts.
Downloads the raw .h5ad, DuckDB, and sidecars.
⚠ Caveats known issues — never the default tab; opt-in only.

The top-right visualize ▾ dropdown is the plot launcher — it opens an interactive form for scatter, hexbin, KDE, violin, dot-plot, heatmap, forest / volcano / MA (DE), and the rest.

Genesets

  • /genesets — three tabs: gene sets (curated registry), starCAT (weighted programs), find by gene (reverse lookup).
  • /genesets/<study>/<experiment> — one experiment's set list.
  • /genesets/<study>/<experiment>/<name> — one gene set plus a where it varies most panel.
  • /genesets/variability — fleet-wide module × dataset variance-explained heatmap.
  • /genesets?group=bygene — type a gene, find every set it belongs to.

Filters, sorting, shareable views

  • Multi-select popovers live on the column headers of the landing table and most drilldown tables. Zero-checked reads as "all". A blue tint on the button = an active filter.
  • Sort — click a header title (not the popover button) to sort by that column.
  • Shareable URL state — the landing page and several drilldowns encode filter + sort state as a #mv=key=val;key=val hash. Copy the URL, paste anywhere; the same view opens.
  • Selection state that isn't in the URL (dropdowns, tabs) is stored per-browser via localStorage, so it survives a reload.

Canonical tags

Fields prefixed ant_ — ant_braak, ant_sex, ant_donor, ant_apoe, ant_diagnosis, and so on — are the site's controlled vocabulary. They render in bold with a subdued canonical pill; the tooltip carries the raw column name.

These are what analytics + curation index on; use them when you're grouping/coloring/filtering plots.

Icons you'll see

  • ⚗ Lab beaker — dataset generated in-house.
  • 🌐 Globe — imported / public dataset.
  • Small chart glyphs next to obs fields (histogram, ECDF, UMAP dot, hexbin) — quick launchers for the matching plot geom on that column.
  • ⚠ in the collection list means the dataset has caveats worth reading.

Preferences

The 👤 dropdown → Preferences page holds per-browser settings kept in localStorage:

  • Module-scoring algorithm — scanpy (default) or UCell.
  • Favourite genes — pinned to the top of gene lists and marked with a star in the gene atlas.

Nothing here is server-persisted. Clearing your browser data resets these to defaults.

The data assistant (chat)

The 💬 button (bottom-right, when enabled for your deployment) opens an in-app chat that can navigate you to plots, filter tables, and answer questions about the catalogue. Your messages are stored on this server and forwarded to an external model provider; the underlying single-cell data itself is never sent — see the privacy note.

REST API

Every server-rendered view is backed by ant-serve, a REST API you can hit directly. The API link in the topbar opens the Swagger UI at /api/docs. A Python client (pyvark) and a Go CLI (vark) ship separately; see the topbar link or ask in-lab for access.
