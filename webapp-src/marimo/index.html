Interactive notebooks

marimo notebooks that run entirely in your browser via Pyodide. Each is a focused view onto the Anthive REST API; widget state is mirrored to the URL bar so any view is one copy-paste from sharing.

Gene expression

Distribution of a single gene across cells — histogram, ECDF, or KDE — with summary statistics.

UMAP / embedding scatter

2-D embedding scatter, with cells colored by gene expression, a numerical obs field, or a categorical field.

Categorical breakdown

Box / violin / bar plot of a gene or numerical obs field split by a categorical field. Or a simple cell-count bar chart per category.

Numerical obs distribution

Distribution of a numerical obs field (QC metrics, module scores) — optionally grouped by a categorical field.
URL parameters: ?db_id=…&gene=…&api=… work on every notebook. Widget state writes back to the URL on every change.
