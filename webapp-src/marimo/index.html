Interactive notebooks

Reactive notebooks running entirely in your browser via Pyodide. Pick view for the streamlit-replacement (controls + plot, no code visible) or edit for the full marimo editor (modify cells, save to your browser).

Gene expression
Distribution of a single gene — histogram, ECDF, KDE — with stats.
view edit
UMAP / embedding scatter
2-D embedding coloured by gene, numerical obs, or categorical.
view edit
Categorical breakdown
Box / violin / bar plot split by a categorical obs field.
view edit
Numerical obs distribution
QC metrics, module scores — distribution with optional grouping.
view edit
URL parameters work on every notebook: ?db_id=…&gene=…&api=…. Widget state writes back to the URL on each change, so any view is one copy-paste from sharing.

Edit mode persists your changes in your browser's local storage (per-origin, per-browser). Edits are not saved back to the server — if you want a clean copy back, just reload view.
