# Anthive Web Browser

HTML interface for browsing h5ad datasets.

## Architecture

**Dual-port design** for clean separation:
- **Browser server**: Port 8081 (`bin/ant-browse`)
- **API server**: Port 8080 (`bin/ant-serve`)
- **Reverse proxy**: Port 8501 (Caddy or nginx) routes to both

## Structure

```
webapp-browser/
  templates/
    base.html          # Pico CSS layout, light mode
    index.html         # Folder list with stats
    folder.html        # Dataset list in folder
    dataset.html       # Dataset detail with markdown
  browser.py           # FastAPI routes with URL encoding
  __init__.py
  README.md
```

## Features

- ✓ Light mode, information-dense design
- ✓ Pico CSS (10KB, no build required)
- ✓ URL-safe encoding for `/` in paths
- ✓ Breadcrumb navigation
- ✓ Status indicators (✓ ready, ⚠ not converted, ✗ not checked)
- ✓ Markdown rendering for .md files
- ✓ htmx ready (loaded from CDN)
- ✓ Read-only (no file uploads)

## Running

**Development (3 terminals):**
```bash
# Terminal 1: API server
make serve-api

# Terminal 2: Browser server
make serve-browse

# Terminal 3: Reverse proxy
make serve
```

Then open: http://localhost:8501

**Production:**
Use a process manager (systemd, supervisor) to run all three services.

## URL Routing

Via reverse proxy (Caddy/nginx on port 8501):
- `/` → Browser home (port 8081)
- `/browse/*` → Browser routes (port 8081)
- `/api/*` → REST API (port 8080)
- `/jupyter` → JupyterLite (static files)
- `/stlite` → Streamlit (static files)

## URL Encoding

File paths with `/` are URL-encoded using `urllib.parse.quote/unquote`:
- Folder: `data/Sierksma2025` → `/browse/Sierksma2025`
- Dataset: `Single.Grafts/prs.singleline` → `/browse/Sierksma2025/Single.Grafts%2Fprs.singleline`

This ensures paths with slashes work correctly in URLs.

## Metadata

The browser reads:
- `.h5ad` files - for file existence and size
- `.md` files - for metadata (cells, genes, layers, obs columns)
- `.duckdb` files - for conversion status

Metadata is parsed from YAML preambles in `.md` files generated by `ant-check`.

## Templates

All templates extend `base.html` and use Pico CSS for styling.

**base.html** provides:
- Header with navigation
- Pico CSS from CDN
- htmx from CDN
- Custom styles for data tables and status indicators

**index.html** shows:
- Folder list with dataset counts
- Summary statistics
- Conversion status

**folder.html** shows:
- Dataset list in folder
- Dataset details (cells, genes, layers)
- File sizes and status

**dataset.html** shows:
- Markdown content from .md file
- Observation columns
- Layers and embeddings
- Links to API endpoints and JupyterLite

## Authentication

Authentication is handled by nginx/Caddy using HTTP Basic Auth.
The browser application itself has no authentication.
