## Results — R1, R2, R3 (2026-08-21 first pass)

### R1 — Gene stats slow on Gene page, no spinner — ❌ FIXED (commit 844fd33)

Root cause: the `.plot-loading` / `.spinner-lg` CSS rules were defined only
inside `plot.html`; `genes.html` used the same class names but got no
animated spinner (just empty text) — hence "blank-looking screen". Moved
the utility to `base.html` so every page renders a real spinner.

Playwright evidence (post-fix):
`/genes/TREM2` at t=200ms shows `spinner-lg` element with computed
`display:flex` and visible animated ring (screenshot `r1_during_load.png`).
Cold `/api/gene_stats_all` takes 11–24 s; warm ~3 s. Server side is
already parallelised (12-worker ThreadPoolExecutor over 40+ datasets) —
no per-request speedup shipped this pass; the spinner covers the wait
adequately.

### R2 — DE page links broken — ✅ VERIFIED WORKING

Playwright walked the DE tab on `SF9/SAN`, `S25/V6A`, `S25/V6W`; expanded
each term, selected each contrast, and followed **every** gene-row action
link (🌋 volcano / 🗺 scatter / 🌲 forest) plus the dataset-tab entry
links (browse / MA / heatmap). All returned HTTP 200 and rendered a
blob-fetched PNG (or a helpful "narrow the selection" 400 for the
DE-heatmap on 28 898 genes, which is expected behavior, not a broken
link).

No fix required; likely the user was on a page where the DE-heatmap
overflow message was mistaken for a broken link.

### R3 — "No rows match — widen the filters" without any filters — ❌ FIXED (commit 8069017)

Root cause: `_module_view.html`'s empty-state message conflated three
distinct conditions. The dataset scope on 17 datasets (including
`S25/V6A`, `S25/V6W`, `B26/SOT`, `D26/ALL`, `F26/MTM` …) has module
scores in the obs table but **no module-variability statistics computed
yet**, so `/module-variability?dataset=…` returns zero rows. The
client showed the misleading "widen the filters" hint even though there
were no filters to widen.

Fixed by branching the empty-state message on three conditions:
1. `ALL_ROWS.length === 0` → "No module-variability statistics available
   for this scope yet."
2. rows dropped by the canonical-statistic pass (no user filters active)
   → "No rows to display (statistics were dropped by the per-tag
   canonical-statistic step)."
3. user filters exclude everything → "No rows match — widen the filters"
   (unchanged; only shown when a filter is actively narrowed).

Playwright sweep of all 153 datasets: 58 dataset genesets tabs render
rows OK, 17 now show the accurate "no statistics available" message,
78 have no Genesets tab. All 128 geneset drilldown pages render rows.
Previous fix (04b154a) already handled the "no preferred stat" fallback;
this fix covers the "no rows at all" superset.
